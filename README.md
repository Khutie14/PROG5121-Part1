## Project Description
A console-based Java application that registers a user (username, password, SA cell number) and allows login with validation and unit tests.

## How to Run
1. Clone the repository.
2. Run `mvn clean install`.
3. Execute `Main.java` in NetBeans.

## Testing
- Run `mvn test` to execute JUnit tests.
- GitHub Actions runs the tests automatically on every push to `main`.

## Part 2 Features
- Welcome menu with numeric options.
- Send, Store, and Disregard messages.
- Auto-generated Message ID and Message Hash.
- Saves messages to a JSON file.

## Part 3 Features
- Array Lists to manage Sent, Stored, and Disregarded messages.
- New Menu Option 4 for "Stored Messages".
- Search, delete, and display the longest message.
- Comprehensive Unit Tests using JUnit.
