## Project Description
A console-based Java application that registers a user (username, password,
SA cell number) and allows login with validation and unit tests.

## How to Run
1. Clone the repository.
2. Run `mvn clean install`.
3. Execute `Main.java` in NetBeans.

## Testing
- Run `mvn test` to execute JUnit tests.
- GitHub Actions runs the tests automatically on every push to `main`.
